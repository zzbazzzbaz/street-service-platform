# 限流与日志记录说明

## 一、接口限流

使用 `django-ratelimit` 装饰器，基于 Redis 缓存计数。被限流时返回 HTTP 429：

```json
{
  "code": 42900,
  "message": "请求过于频繁，请稍后再试"
}
```

### P0 - 登录类端点（5 次/分钟，按 IP）

| 端点 | 方法 | 限流键 | 文件位置 |
|------|------|--------|----------|
| `/api/admin/auth/login` | POST | IP | `admin_portal/api.py` `admin_login` |
| `/api/auth/wechat-login` | POST | IP | `members/api.py` `wechat_login` |
| `/api/auth/wechat-phone-login` | POST | IP | `members/api.py` `wechat_phone_login` |
| `/api/merchant/auth/wechat-login` | POST | IP | `merchants/api.py` `merchant_wechat_login` |
| `/api/merchant/auth/wechat-phone-login` | POST | IP | `merchants/api.py` `merchant_wechat_phone_login` |

限流键 `ip` 取自 `request.META["REMOTE_ADDR"]`，同一 IP 对同一端点 1 分钟内超过 5 次请求即触发 429。防止暴力撞库和 token 刷量。

### P1 - 支付/积分类端点（20 次/分钟，按用户）

| 端点 | 方法 | 限流键 | 文件位置 |
|------|------|--------|----------|
| `/api/merchants/{merchant_id}/point-payments` | POST | 用户身份 | `merchants/api.py` `public_merchant_point_payment` |
| `/api/merchants/point-codes/{code}/scan` | POST | 用户身份 | `merchants/api.py` `public_point_code_scan` |
| `/api/admin/points/manual-adjustments` | POST | 管理员身份 | `admin_portal/api.py` `admin_manual_adjustment_create` |

限流键取自 `shared/ratelimit.py` 的 `user_key` 函数：

- 认证用户：`{subject_type}:{openid 或 user_id}`（如 `member:test-openid`、`admin:1`）
- 认证失败兜底：`ip:{客户端IP}`

同一用户对同一端点 1 分钟内超过 20 次请求即触发 429。防止异常消费和重复提交刷积分。

### 配置与开关

| 配置项 | 位置 | 说明 |
|--------|------|------|
| `RATELIMIT_ENABLE` | `config/settings.py` | 生产环境 `true`，测试环境自动 `false`（`TESTING` 检测） |
| `CACHES` | `config/settings.py` | 生产用 Redis，测试用 LocMemCache |
| `Ratelimited` handler | `config/api.py` | 全局异常处理器，返回 429 + JSON |

## 二、日志记录

使用 Python 标准库 `logging` + Django `LOGGING` 配置。业务日志 logger 名称为 `street.*`，级别 INFO。

### 日志配置

| 配置项 | 值 |
|--------|-----|
| 业务 logger | `street`（INFO 级别） |
| Django 请求日志 | `django.request`（WARNING 级别） |
| 输出方式 | 控制台 StreamHandler |
| 格式 | `[时间] 级别 logger名 消息` |

### P1 - 资金/积分流水日志

| 业务流程 | 级别 | 文件位置 | 日志内容 |
|----------|------|----------|----------|
| 积分增加 | INFO | `points/services.py` `add_points` | `积分增加 member=X amount=N source=type balance_after=N` |
| 积分扣减成功 | INFO | `points/services.py` `deduct_points` | `积分扣减 member=X amount=N source=type balance_after=N` |
| 积分余额不足 | WARNING | `points/services.py` `deduct_points` | `积分扣减失败余额不足 member=X need=N balance=N source=type` |
| 商户积分支付 | INFO | `merchants/services.py` `pay_merchant_with_points` | `商户积分支付 member=X merchant=Y points=N yuan_amount=N` |
| 商户支付幂等重放 | INFO | `merchants/services.py` `pay_merchant_with_points` | `商户支付幂等重放 member=X merchant=Y request_no=Z record_id=N` |
| 固定码扫码支付 | INFO | `merchants/services.py` `scan_point_code` | `固定码扫码支付 member=X merchant=Y code=Z points=N yuan_amount=N` |
| 固定码扫码幂等重放 | INFO | `merchants/services.py` `scan_point_code` | `固定码扫码幂等重放 member=X merchant=Y code=Z request_no=W record_id=N` |
| 商户结算处理 | INFO | `admin_portal/services.py` `process_settlement` | `商户结算处理 settlement=N merchant=X processor=Y total_points=Z` |

### P2 - 外部集成与异常兜底日志

| 业务流程 | 级别 | 文件位置 | 日志内容 |
|----------|------|----------|----------|
| 微信接口网络请求失败 | ERROR | `shared/wechat.py` `_get_json` / `_post_json` | `微信接口请求失败 url=X reason=Y` |
| 微信接口返回错误码 | WARNING | `shared/wechat.py` `_parse_wechat_response` | `微信接口错误 errcode=X errmsg=Y` |
| 微信接口返回非 JSON | ERROR | `shared/wechat.py` `_parse_wechat_response` | `微信接口返回非JSON 原始响应=...` |
| Token 解析失败 | WARNING | `shared/auth.py` `parse_token` | `token 解析失败` / `token 签名无效` / `token 已过期` 等 |
| Token 主体类型不支持 | WARNING | `shared/auth.py` `parse_token` | `token 主体类型不支持 subject_type=X` |
| 全局业务异常 | WARNING | `config/api.py` `business_errors` | `业务异常 path=X method=Y code=Z message=W` |
| 全局未处理异常 | ERROR | `config/api.py` `catch_all` | `未处理异常 path=X method=Y`（含堆栈） |
| 限流触发 | WARNING | `config/api.py` `ratelimited_errors` | `限流触发 path=X method=Y` |

